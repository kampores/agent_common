## 1. 実行モードと条件付きローカル切り替え

環境変数 `LLM_PROVIDER` が設定されている場合、プロファイルの `provider_str` より優先されます。

| モード | 動作 |
| :--- | :--- |
| `external` | 外部 API 呼び出しのみを実行。サービス無効化または API キー未設定時は `None` を返却。 |
| `local` | ローカルモデルのみを実行。 |
| `auto` | 外部呼び出しの結果が `None` の場合、同一プロファイル内のローカル設定で推論を実行。 |

> ⚠️ **`auto` モードに関する重要な境界条件**:
> `auto` は外部ネットワーク障害の全自動復旧を意味するものではありません。外部 API が `HTTPError` や `URLError` などの通信例外を送出した場合、ローカルへフォールバックせず呼び出し元へ例外がそのまま送出されます（Fail-Fast）。外部呼び出しが設定により無効化されているか正常に `None` を返却した場合にのみローカルモデルが実行されます。
> `auto` を有効にするには、**同一のモデルプロファイルブロック内**で外部パラメータとローカルパラメータ（`model_path_str`, `n_ctx_int` 等）を同時に宣言する必要があります。
